# BALACOCO — منصة تعليم علم المعاني

منصة تعليمية تفاعلية لدراسة علم المعاني، مبنية باستخدام Next.js وTypeScript وTailwind CSS.

## متطلبات التشغيل
- Node.js 20.9 أو أحدث.
- npm.

## التشغيل المحلي على Windows PowerShell
افتح مجلد المشروع الذي يحتوي على `package.json`، ثم نفّذ:

```powershell
npm.cmd install
npm.cmd run dev
```

افتح بعد ذلك: http://localhost:3000

إذا ظهرت مشكلة في تثبيت الحزم، أرسل رسالة الخطأ كاملة من الطرفية ولا تحذف مجلد المشروع.

## البناء للإنتاج

```powershell
npm.cmd run build
```

## النشر
ارفع المجلد إلى مستودع GitHub، ثم اربط المستودع بمشروع Vercel. يكتشف Vercel إعدادات Next.js تلقائيًا.

## محتوى المنصة
- الصفحة الرئيسية باللغة الإندونيسية.
- صفحات التعلّم باللغة العربية.
- تسع وحدات تفصيلية في علم المعاني.
- نماذج للتحليل البلاغي.
- مكتبة نصوص تضم آيات قرآنية وحكمًا ونصوصًا تدريبية.
- اختبار تفاعلي وبطاقات تعليمية.
- لوحة متابعة التقدّم ومساحة للتطبيق.

## ملاحظة علمية
النصوص القرآنية مرتبطة بمراجع السور والآيات. والأبيات التدريبية التي أنشأتها المنصة موسومة بوضوح ولا تُنسب إلى شاعر تراثي. ينبغي مراجعة التحليلات في ضوء كتب البلاغة والتفسير المعتمدة.

## التخزين
يحفظ إصدار البداية تقدّم المتعلّم محليًا في المتصفح باستخدام `localStorage`. ملف `supabase/schema.sql` يتضمن مخططًا أوليًا للتوسّع إلى قاعدة بيانات ومزامنة حسابات المستخدمين.
